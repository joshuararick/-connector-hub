Security

Security rules for this owned version.

  • Never store production API keys, tokens, passwords, refresh tokens, or private keys in this browser-only site.
  • Use placeholders until a private backend, Cloudflare Worker, or secure API layer is added.
  • Host only over HTTPS.
  • Add real authentication before storing private team/customer data.
  • Use least-privilege API keys, rotate secrets, and keep backups safe.
  • Recommended backend later: server-side environment variables or a secrets vault, not localStorage.

Deploy

Deploy it as your own website.

The B12 website is the production front door. This GitHub version is the functional command-center app and backup. Embed or link it from B12 so visitors can launch the working agent registry without storing private secrets in B12.
